# 🛡️ Cybersecurity Projects

Colección de proyectos personales de ciberseguridad. Cada carpeta es un proyecto independiente con su propio `README.md`, dependencias y forma de ejecutarse.

## Proyectos

- [`mapa-riesgos-digitales/`](mapa-riesgos-digitales/) — Evalúa hábitos digitales de una persona (contraseñas, actualizaciones, redes, respaldo, seguridad física del dispositivo) y genera un mapa de riesgo visual con un plan de acción priorizado.  Combina un motor de reglas explicable con un modelo de Machine Learning ligero. Corre 100% local (Flask o Streamlit), sin enviar datos a servidores externos.
- [`fit-score-reclutamiento/`](fit-score-reclutamiento/) — Sistema de cribado de CVs frente a una vacante: modelo de ML entrenado (no un simple prompt) que calcula un score de ajuste explicable con SHAP, detecta CVs duplicados/plagiados entre candidatos, audita sesgos del proceso (regla del 80%) y recomienda upskilling a candidatos casi aptos. 100% local, sin API externa.
